# WC Engenharia — site institucional em React

Site institucional responsivo em React + Vite, com identidade visual dourada.

## Executar
Requer Node.js 18+.
```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
npm run preview
```

## Personalização
- Conteúdo e seções: `src/main.jsx`
- Cores, animações e responsividade: `src/styles.css`
- Ícone da marca: `public/wc-icon.svg`
- Fotografias ilustrativas: URLs externas do Unsplash; confirme os termos/licenças aplicáveis e substitua por imagens próprias ou licenciadas antes de publicar.
- Os textos de avaliações estão marcados como fictícios/demonstrativos. Não os apresente como depoimentos reais.
- O formulário é apenas demonstrativo: não transmite nem armazena dados. Para receber mensagens, conecte um serviço seguro e revise a Política de Privacidade.
- A Política de Privacidade incluída é um modelo inicial e precisa ser preenchida com os dados reais da empresa, fluxos de dados, serviços integrados, retenção e canal de contato; valide juridicamente antes de publicar.
- Adicione os canais oficiais de redes sociais da WC Engenharia quando estiverem disponíveis.

## Deploy na Vercel
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
